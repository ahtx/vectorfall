# Credits for the sample data

VectorFall ships a small demo set so that every lab works on first run. The files are in `app/sample_data/`.
VectorFall adds them once to a new installation (see `app/samples.py`). This file lists the source and licence of
each item. The Photo Lab and the Sound Lab show the same credit next to each sample.

## Text

- **Essays by Amir Husain (Forbes)**: 35 essays published on forbes.com, 2019-2023, included by the author.
  We removed the page parts (navigation, advertisements, share bars, image captions and credits)
  and kept the title, date and body text. `app/sample_data/third_party/forbes/`.
- **Twenty classic novels**: public-domain texts from Project Gutenberg (https://www.gutenberg.org), with the
  Project Gutenberg header and licence removed. `app/sample_data/third_party/classics/`.
- `app/sample_data/lm/classics/` holds the small neural language model that VectorFall trained on the classic
  novels (no other text).
